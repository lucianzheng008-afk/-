# 史料机构导航（2026-10-09 实测快照）

按形成机关与收藏链选择资源，不按网站数量选。以下逐项区分本次访问证据、平台声明与尚未实测功能。日期只是本次检查日期；下次任务实时核对。HTTP200、主页可读、搜索摘要、目录可读、正文可读、原图核对是不同层级。官方入口列表中的失败项只作明确待核线索，不列为已核全文库。

安装时使用可用 web 工具；独立Python公开GET保留TLS验证，修复Python缺失CA路径后显式使用系统CA `/etc/ssl/cert.pem`。仍证书失败的站点未关闭验证。网络日志在交付验收材料中。入口的馆藏范围用于定位；具体时期、免费/注册/订阅/到馆以及号码搜索语法必须以该次记录页和帮助为准。
