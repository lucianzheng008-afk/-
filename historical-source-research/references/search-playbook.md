# 检索与反向追踪

## 解析与需求矩阵

输入可为完整问题、事件/时期/双边关系、人物/机构、事实/论断、标题/号码、论文段落脚注、争议解释或因果机制。将问题拆为可分别考证的命题，不直接复制长问题到搜索引擎。列时间、地域、行为体、机构历史名称、相关语言、产文与收藏机关、竞争解释、文件需求；范围过宽时先做最相关时期的小规模定位，并说明实际范围。

|命题|应观察的事实|可能文书|收藏路径|替代来源|
|---|---|---|---|---|
|某政策由领导人推动|何时获得信息、指示及部门反馈|领导人通信、会议记录、内阁档案、政策备忘录|领导人/内阁档案与部门移交档案|当时日记、正式文书集；回忆录另标事后层级|
|谈判条件发生调整|各方指令、草案变化及批准|谈判指令、会谈纪要、草案、非正式通信、条约附件|谈判双方外交/政府档案，国际组织|第三方使馆报告，公开声明作为公开立场|
|政策执行影响结果|传达、资源配置、执行反馈|军情评估、执行报告、地方文书、内部总结|军政部门与地方馆藏|同时代统计、私人通信、报刊作为外部观察|

## 词表与语法

七层词表：事件常称；姓名及历史罗马化；政府旧名；当时实际术语；文书类型；日期/地点/会议/编号；旧译名和拼写。只选择与对象相关的简繁中文、英文、日文、法德俄等。保留检索时原式，不将中文标题的自行翻译当作文件原题。

记录语种、每次实际查询、UI字段、筛选、排序、分页和语法是否已验证。通用引擎的 `site:`、引号与 OR 不保证能在馆内搜索使用；布尔/日期/编号查询要先看本库帮助或实际界面。初始检索可用短词，再按形成机关、系列和年代缩窄。原件文本未 OCR 时，目录无词命中不意味着文件无内容。

历法保留原记法、转换结果与依据：民国年通常需加1911，仍核查是否为民国纪年而非文件号；日本年号先核对应年与月份，改元当年不能只按年份替换；儒略/格里高利、旧历/公历、时区、拟稿/发出/收到日均不混同。不能确切转换时 normalized date 留空。公元前、约年、日期区间也保留原记法和精度，不能为数据库方便虚构某天。

## 定位与跨馆藏

依产生机关的权限和行政史寻找国家、外交、总统/首相、军事、议会、国际组织、地方、大学特藏和私人文书。核实历史继承、档案移交、分藏与旧编号；数据库通常是提供者，不能替代收藏机构。以记录页给出的永久链接和原始 reference 搜索其他版本，保留旧新编号对应的证据。

逐次比较独立记录链：不同国家、部门、谈判方、同时代/事后、公开/内部。先看核心命题是否有材料可判，再决定扩展；停止时报告未覆盖的机关/时期/语种。不得固定要求每个命题必须有若干档案，也不得单库命中多就结束。

## Footnote-to-Archive

1. 将完整脚注作为未核验引用链保存，拆出机构缩写、全宗、系列、箱/卷、文件号、题名、日期、引文页。缩写不明先查作者缩写表与馆方说明，不凭印象展开。
2. 查官方目录，比较题名/日期/形成机关/引用层级；编辑题名可能不同于原件标题。记录 record 与 item 的区别，箱号不等于文件唯一标识。
3. 有数字正文则对读页码、删节、省略号、译文、前后语境；只找到目录则停止于元数据层级。出版史料的 source note 只是它所载的原档出处，并非已现场验证保管位置。
4. 沿系列层级查看相邻件、前后时间与相应部门/国家材料，禁止自动生成不存在的相邻编号。冲突出处保留并列版本。
5. 无原件：列准确已知线索、馆方查阅规定入口、到馆/注册/订阅/调卷状态与待问问题。可以拟询问函，未经用户授权不发送，不替用户注册付费。

## 两个研究场景（检索式是计划，执行后才进入日志）

1971—1972年中美缓和：美国白宫/NSC、国务院及使馆材料、FRUS XVII/E–13、Nixon Library；中国形成机关的中央/外交决策文件需单独确认开放政策。近史所或国史馆的台湾方面观察不能替代北京内部决策记录。扩词 Nixon / Kissinger / Mao Tse-tung / Mao Zedong / Chou En-lai / Zhou Enlai / Peking / Beijing，秘密接触、访华、会谈纪要、渠道与谈判指令；第三国中介记录如巴基斯坦相关材料按已证线索扩展。会谈中表述不能自动证明此前真实动机或完整双方内部链条。

1920年代北洋关税交涉：先分华盛顿会议、北京关税特别会议与具体后续谈判，勿把1928年后国民政府记录统称北洋。中文「關稅／關稅自主／關稅特別會議／裁厘加稅／釐金」、英文 customs autonomy / tariff conference / Peking / Chinese Maritime Customs、日文「支那關稅／支那関税／北京会議／厘金／治外法権」；历史词仅用于定位并注明时代用语。近史所外交档案、第二历史档案馆及海关馆藏须查移交/权限；FRUS 1920年代、英国外交档案、JACAR/日本外交史料可寻找外方指令。日文档案里的中国政府表述仍是外方记录。
